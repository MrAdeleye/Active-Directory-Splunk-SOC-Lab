 <h1> Active-Directory-Splunk-SOC-Lab  </h1>
Teaching Windows to talk. Teaching Splunk to listen. Learning what happens when things go wrong


<h2>Description</h2>
This project is a hands-on security monitoring lab built with VirtualBox, Windows Server, Windows, Sysmon, Splunk, and an increasingly suspicious number of troubleshooting sessions.

The goal is to build a small enterprise-style environment, collect endpoint telemetry, centralize logs in Splunk, and eventually use that data to investigate suspicious activity.

Not just installing security tools and admiring the dashboards. I want to understand what the logs are telling me, how to investigate them, and how to turn findings into useful detections.



<br />

<h2> Target Goal </h2>




<h2> Target Goal </h2>
The primary goal of this lab was to  :

- <b>Perform host discovery and service enumeration.
- <b>Identify vulnerabilities using OpenVAS.
- <b>Prioritize vulnerabilities based on business risk.
- <b>Recommend realistic remediation strategies.
- <b>Document findings in a professional format.


<h2> Actions Performed </h2>
 
- <b>Verified network connectivity.
- <b>Performed service enumeration with Nmap. 
- <b>Created and configured OpenVAS  alongside its  scan target.
- <b>Executed a Full and Fast scan.
- <b>Reviewed vulnerability findings.
- <b>Prioritized vulnerabilities by severity and exploitability.
- <b>Developed remediation recommendations.
- <b>Validated findings against exposed services.
